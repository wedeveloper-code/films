# FastWP — WordPress тема для онлайн-кинотеатра

## Технические требования

### Серверная среда
- **PHP:** 8.1+
- **Обработчик:** Модуль Apache (mod_php)
- **WordPress:** 6.4+
- **Рекомендуется:** GD или Imagick для обработки изображений

### Производительность
- Тема проходит тесты Google PageSpeed Insights (LCP < 2.5s, CLS < 0.1)
- Валидный HTML5 (validator.w3.org)
- Отсутствие внешних запросов (всё самостоятельно)
- CSS и JS минимизированы
- Изображения с `loading="lazy"`, первые постеры с `fetchpriority="high"`

### Зависимости
- **Никаких внешних CDN** — все скрипты и шрифты самостоятельные
- **Inter** — бесплатный шрифт (SIL Open Font License), self-hosted, поддержка кириллицы
- **Vanilla JS** — без jQuery, без фреймворков

## Структура данных WordPress

### Посты и категории
- **Записи (Posts)** — каждая запись = карточка фильма
- **Категории (Categories)** — стандартная иерархия:
  - Фильмы (`films`)
  - Сериалы (`series`)
  - Телепередачи (`tv`)
  - Новинки (`new`)
  - Жанры → Боевик, Комедия, Драма…
  - Год → 2024, 2025, 2026…
  - Актёры → конкретные актёры

### Мета-поля фильма

| Ключ | Тип | Описание |
|------|-----|----------|
| `movie_gallery` | array[4] | ID четырёх изображений из медиатеки |
| `movie_year` | int | Год выпуска |
| `movie_genre` | string | Жанр(ы) |
| `movie_duration` | string | Длительность (напр. "1ч 55м") |
| `movie_quality` | string | Качество (HD, 4K, FullHD) |
| `movie_translation` | string | Тип перевода |
| `movie_rent_1` | int | Аренда — 1 просмотр (₽) |
| `movie_rent_3` | int | Аренда — 3 просмотра (₽) |
| `movie_rent_5` | int | Аренда — 5 просмотров (₽) |
| `movie_buy_week` | int | Покупка на неделю (₽) |
| `movie_buy_month` | int | Покупка на месяц (₽) |
| `movie_buy_forever` | int | Покупка навсегда (₽) |
| `movie_coupon` | string | Код купона на скидку |
| `movie_views` | int | Счётчик просмотров карточки |

## Возможности темы

### Главная страница
- H1 с количеством фильмов в каталоге (кэшируется)
- 4 блока категорий: Фильмы, Сериалы, Телепередачи, Новинки
- В каждом блоке 2 строки по 5 фильмов (10 штук)

### Карточка фильма
- 4 фотографии с переключением при наведении мыши
- Название + таблица (год, жанр)
- 6 ячеек цен: аренда (1/3/5 просмотров) + покупка (неделя/месяц/навсегда)
- Скрытый купон на скидку (нажать для показа и копирования)
- Счётчик просмотров карточки
- Кнопка "Избранное" (сердечко) — хранится в cookies 7 дней

### Шапка
- Логотип FASTWP
- Навигация: Фильмы, Сериалы, Телепередачи, Новинки
- Иконка поиска
- Шестерёнка: Войти, Регистрация, переключатель темы

### Темы оформления
- Тёмная тема (по умолчанию)
- Светлая тема
- Выбор сохраняется в localStorage

### Изображения
- Автоматическая конвертация в WebP при загрузке
- Автоматическое сжатие до 200KB максимум
- Сохранение пропорций при масштабировании

## Установка

1. Скопировать папку `fastwp` в `/wp-content/themes/`
2. Активировать тему: Внешний вид → Темы → FastWP
3. Создать главную страницу: Страницы → Добавить → установить как главную
4. Создать категории: Фильмы, Сериалы, Телепередачи, Новинки
5. Добавить записи (фильмы), привязать к категориям, заполнить мета-поля
